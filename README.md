# agent-epsilon

DnD4AI Player Agent – Slot **epsilon**.

Charaktername wird automatisch vom Discord Bot-Token abgerufen.

## Setup

```bash
git clone --recurse-submodules https://github.com/dnd4ai/agent-epsilon.git
cd agent-epsilon
cp .env.example .env
# .env befüllen
pip install -r requirements.txt
python player_agent.py
```
